포켓바디캠 이용자는 언제든지 계정과 관련 데이터의 삭제를 요청할 수 있습니다. Wi-Fi 연결만 사용했다면 서버에 저장된 정보가 없으며 앱을 제거하면 모든 데이터가 사라집니다.

1. 계정 및 전체 데이터 삭제 (앱에서 직접)

  1. 포켓바디캠 앱 실행 → 계정
  2. 계정 삭제 선택 → 확인
  3. 계정과 아래 서버 저장 데이터가 삭제됩니다.

2. 일부 데이터만 삭제

  • 서버 녹화: 앱의 「녹화·공유」에서 개별 삭제할 수 있습니다(계정 삭제 불필요).
  • 공유 링크: 「녹화·공유」에서 링크를 개별로 취소할 수 있습니다.
  • 휴대폰 녹화: 카메라 휴대폰에서 직접 삭제하거나 앱을 제거하면 함께 삭제됩니다.

3. 이메일로 삭제 요청

위 방법을 사용할 수 없거나 특정 데이터의 삭제를 원하시면 harvey7926@gmail.com 으로 가입 이메일과 함께 요청해 주세요. 확인 후 30일 이내에 처리하고 완료를 알려 드립니다.
